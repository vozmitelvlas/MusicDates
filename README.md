# MusicDates

Веб сервис для поиска муз встреч(людей, площадок). В рамках работы реализована категория "Муз площадки".

### Реализовано

- Авторизация пользователя
- Регистрация пользователя
- Создание муз. события (после входа/регистрации)
- Просмотр карточки события
- Редактирование события (доступна создателю события)
- Удаление события (доступно создателю события)
- Просмотр всех пользователей (админ)
- Удаление пользователя (админ)
- Смена роли пользователя (админ) 

### Стек

React · JS · Redux · Vite · Nodejs · Express · MongoDb · Bcrypt
